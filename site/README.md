# Blueprint site

`index.html` is the PaperOS Core Platform blueprint page, published as a Claude artifact at https://claude.ai/artifact/M8PdehTznioG49QJUnkWTU and mirrored here. It is a single self-contained file (no external scripts, fonts or images) generated by `tools/blueprint/build_v3.js` from `plan/linear-snapshot-live.json`, `plan/plan.json`, `plan/linear-ids.json` and `plan/model-effort.json`. `data.json` is the aggregated data the page embeds (projects, project-to-project blocking edges, milestones, the critical chain, every issue), written alongside for other tools.

Sections: where the build stands today (counts, pipeline, phases, what needs Justin), an interactive project dependency map and the longest blocking chain, progress bars per project, a milestone timeline with swimlanes, the architecture diagram and decisions, the collapsible agent org chart, the credit split and model/effort matrix, the documents to read, risks, and the searchable issue index.

`previous/index-v2.html` is the page this one replaced (round-2 version, 2026-09-17).

The workflow in `.github/workflows/pages.yml` publishes this folder to the `gh-pages` branch on every push to `main`, so GitHub Pages serves it at `https://imagine-os.github.io/linear-builder/`. `.nojekyll` keeps Pages from running Jekyll over the files.
