# Blueprint site

`index.html` is the PaperOS Core Platform blueprint page, published as a Claude artifact at https://claude.ai/artifact/M8PdehTznioG49QJUnkWTU and mirrored here. It is generated by `tools/blueprint/build_v5.js` (round 4; `node tools/blueprint/build_v5.js`, `PAPEROS_ARTIFACT_OUT=<file>` also writes the self-contained artifact body) from `plan/linear-snapshot-live.json` (2026-09-18T14:58Z), `plan/plan.json`, `plan/linear-ids.json`, `plan/round4/chunks-v2.json` (the round-4 chunk plan; `CHUNKS=` overrides it), `plan/round4/` and `docs/linear-features.md`; the Pages copy loads the 3d-force-graph library from jsDelivr for the two WebGL views and the artifact copy is fully self-contained. `data.json` is the aggregated data the page embeds (projects, project-to-project blocking edges, milestones, the critical chain, every issue), written alongside for other tools.

Sections (v5): where the build stands today (counts, Triage and Needs Justin tiles, points, pipeline, phases), the five initiatives, the C1/C2/C3 cycle strip, points per project and the burn-up, what round 4 changed (23 projects, twelve gaps, the Linear features table), the seven filterable views, modules and plug points, the $2,500 chunks, an interactive project dependency map and the longest blocking chain, progress bars per project, a milestone timeline with swimlanes, the architecture diagram and decisions, the collapsible agent org chart, the credit split and model/effort matrix, the documents to read, risks, and the searchable issue index.

`previous/index-v4.html` is the page this one replaced (round-3 version, 2026-09-17); `previous/index-v3.html` and `previous/index-v2.html` are the earlier ones.

The workflow in `.github/workflows/pages.yml` publishes this folder to the `gh-pages` branch on every push to `main`, so GitHub Pages serves it at `https://imagine-os.github.io/linear-builder/`. `.nojekyll` keeps Pages from running Jekyll over the files.
