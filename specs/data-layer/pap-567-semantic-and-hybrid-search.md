# PAP-567: Semantic and hybrid search: `EmbeddingProvider`, `search.embed` job, pgvector HNSW column, RRF fusion, reindex on model change and the `<SearchResults/>` component

**Model / Effort:** Sonnet 5 (`claude-sonnet-5`) / medium — Build M

**Goal**

Second child of PAP-39: add meaning. An `EmbeddingProvider` behind an OpenAI-compatible endpoint (self-hosted `text-embeddings-inference` on staging) fills a `vector(1024)` column through a job, `search.query` gains `semantic` and `hybrid` modes fused with reciprocal rank fusion, model changes trigger a reindex, and one `<SearchResults/>` component renders grouped results with empty and error states.

**Scope**

In: `packages/search/src/{embed,provider,fusion}.ts`, column `embedding vector(1024)` with HNSW index and `embedding_model text`, job `search.embed` (PAP-43), `EmbeddingProvider` interface with `openai-compatible` and `fake` adapters, `ops/compose/embeddings.yml` (staging only), `search.query` modes, `<SearchResults/>` in `@paperos/ui`, docs section.

Out: Keyword core (sibling), RAG or chat over results, per-tenant models.

**Spec**

* `EmbeddingProvider { model, dims, embed(texts: string[]): Promise<number[][]> }`; env `EMBEDDINGS_URL`, `EMBEDDINGS_MODEL`; batches of 64 texts; provider down leaves keyword results working.
* `search.embed` enqueued by the upsert trigger path when `embed: true` in the registration; stores `embedding_model` per row; `pnpm search:reindex --model <new>` re-embeds rows whose model differs, in batches with a time box.
* Changing dimensions is a migration (new column, backfill, swap) generated by `pnpm search:migrate-dims`; documented since `vector(1024)` is fixed per column.
* `hybrid` = RRF over keyword and vector top-100 lists with `k = 60`; deterministic tie-break by `updated_at desc`; `semantic` alone requires the provider and returns `PROVIDER_UNAVAILABLE` otherwise.
* Latency at 100k documents: hybrid p95 under 250 ms on staging with the embedding container; bench committed.
* `<SearchResults items facetCounts mode onSelect />` groups by entity type, shows snippets and a mode toggle; states loading, empty, error, provider-unavailable; keyboard navigable.

**Interface contract**

Provides: `EmbeddingProvider`, job `search.embed`, `search.query` modes `semantic|hybrid`, scripts `search:reindex`, `search:migrate-dims`, component `SearchResults`.

Consumes: Sibling registry and table, jobs (PAP-43), `vector` extension (PAP-30, PAP-42), UI primitives (PAP-71, PAP-236 to PAP-238), env schema (PAP-17). Consumed by PAP-138, PAP-151.

**Definition of done**

* Semantic mode answers "billing team" with the finance workspace on the demo seed against the staging container; hybrid bench at 100k documents committed.
* Reindex on model change re-embeds only stale rows (test); provider outage leaves keyword results intact (test).
* `<SearchResults/>` at 375, 768, 1280, 1920 including empty, error and provider-unavailable states; axe clean.
* Docs section; CHANGELOG; Linear comment with the bench and Storybook link.

**Test plan**

* Unit: RRF determinism and tie-break, batch splitting, model-staleness query, provider error mapping, component state matrix.
* E2E: CI compose with the `fake` provider: embed job fills vectors, hybrid query returns fused order; Playwright story capture at four widths.

**Demo**

Reviewer types "acme" then switches the toggle to semantic and searches "billing team"; opens Storybook to see the provider-unavailable state. Under a minute.

**Edge cases**

* Body over the cap: only the first 100 KB embedded; flag shown in the dictionary.
* Provider returns wrong dimensions: row skipped and job dead-lettered with the model name.
* Tenant language `simple` with semantic mode: vectors are language-agnostic; documented.
* HNSW build on 1M rows: `maintenance_work_mem` note in the runbook.
