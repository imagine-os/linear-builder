# PAP-688: Pseudo-locale and RTL visual run: capture the Gate 3 page set in `en-XA` pseudo-locale and `ar` RTL at three widths nightly, flagging truncation and mirrored-layout defects

**Model / Effort:** Sonnet 5 (`claude-sonnet-5`) / medium — Build S

**Goal**

Deferred to v0.2 by round 4 (not claimable before 2026-10-01; NJ-14 can reinstate). PAP-27 adds ICU catalogs, RTL flip and a pseudo-locale, and PAP-375 pseudo-locale validation for spec copy, but Gate 3 only screenshots English left-to-right. A nightly capture of the page set in `en-XA` (30 percent longer strings, accented) and `ar` (RTL) at three widths makes truncation and unmirrored icons visible to the vision agent.

**Scope**

* In: Playwright project variants `pseudo-en-XA` and `rtl-ar` in `playwright.visual.config.ts` at `sm-375`, `lg-1024`, `3xl-1920`, locale fixture setting the PAP-27 negotiation cookie, nightly step in PAP-253, informational baselines under `__screenshots__/i18n/`, vision pass (PAP-84) with the `RUB-VIS-*` truncation and mirroring rules enabled, docs section.
* Out: translating the product, RTL for every locale, per-PR runs (nightly only).

**Spec**

* Locale fixture sets `paperos_locale` cookie and `document.dir`; pseudo-locale generated by PAP-27's `pseudo` transform, so no catalogue authoring is needed.
* Captures use the PAP-247 page list with `screenshot: true`; results are informational (`status: warn`), diffs never block; the vision agent runs with `focus: ['truncation', 'mirroring', 'overflow']` and posts findings to the nightly Linear issue (PAP-253) grouped by page.
* DOM metrics (PAP-84) add `direction` and `textOverflowCount` so RTL and pseudo findings get DOM confirmation.
* Budget: 3 widths × 2 variants × page set under 6 minutes on one shard.

**Interface contract**

* Provides: projects `pseudo-en-XA` and `rtl-ar`, `__screenshots__/i18n/` layout, `focus` option on the vision runner, DOM metric fields `direction`, `textOverflowCount`.
* Consumes: PAP-247 page list and fixtures, PAP-27 locale negotiation and pseudo transform, PAP-84 vision runner, PAP-253 nightly slot.

**Definition of done**

* Nightly run for three nights with contact sheets; seeded fixed-width button truncates in `en-XA` and is caught at S1; seeded unmirrored chevron caught in `ar` (links).
* Docs section; changelog under "Quality".

**Test plan**

* Unit: locale fixture, focus option plumbing, DOM metric fields.
* E2E: nightly capture and vision pass on staging.

**Demo**

Open the nightly Linear issue: the i18n section lists two pages with truncation findings and their annotated thumbnails at 375 px. Under one minute.

**Edge cases**

* Font fallback for Arabic missing in the Docker image: image pin gains Noto Naskh; a missing glyph run prints the environment warning.
* Pseudo-locale breaks a regex-validated field: finding at S2 pointing at the validator, not the layout.
* Pages without `screenshot: true`: skipped, count reported.

**Dependencies**

Hard: PAP-247, PAP-27. Soft: PAP-84, PAP-253, PAP-375.

**Agent**

Builder: Sentinel (Visual Inspector) with Iris. Reviewer: Sentinel (Edge Case Hunter).

**Size**

S: half a session.
