# design-system — Design System
PHASE P0 prio 1 dependsOn []
SUMMARY: DTCG tokens compiled to CSS variables, accessible components on headless primitives with Tailwind v4, themes per tenant, and Storybook as the living document.
DESC: Goal: every page an agent generates looks like one product and passes accessibility by default. Tokens for color, type, space, radius, motion and elevation live in W3C DTCG JSON and compile to CSS variables, enabling light, dark, high-contrast and per-tenant brand themes at runtime. Components are built on Base UI/Radix primitives with Tailwind v4, covering primitives, layout (AppFrame, SplitPane, Inspector, CommandBar) and data display. Storybook with a11y, viewport and interaction addons deploys to GitHub Pages and is what the quality pipeline screenshots. Every component maps to a spec-builder component ID so page specs reference real parts. Non-goals: a bespoke CSS-in-JS runtime or pixel-perfect Figma parity on day one.
MILESTONES: ['Tokens and primitives 2026-09-20: Token pipeline, 20 core components, icons, Storybook live', 'Component library covers app shell needs 2026-09-25: Layout and data-display components, motion, a11y audit', 'Themable per tenant with docs 2026-09-30: Runtime theming, guidelines, spec mapping, Figma decision']

GOAL: Create the single source of truth for every visual decision in PaperOS: colour, typography, spacing, radius, motion and elevation tokens written in W3C DTCG JSON, compiled by Style Dictionary into CSS custom properties, a Tailwind v4 `@theme`, and a typed TypeScript export. Every component in `packages/ui` and every generated page consumes these variables and nothing else.
SCOPE: In:

* Colour defined in OKLCH; 11-step ramps (50-950) for neutral, accent, success, warning, danger, info generated by a `culori` script and checked for WCAG contrast pairs.
* Type scale (`xs` 12 to `4xl` 36, fluid `clamp()` for display sizes), line heights, weights, font stacks (Inter Variable, JetBrains Mono).
* Spaci
SPEC(first 1200): * DTCG format: `{"color":{"accent":{"500":{"$type":"color","$value":"oklch(60% 0.18 260)"}}}}`; aliases via `{color.accent.500}`.
* Style Dictionary config in `packages/ui/style-dictionary.config.ts` with custom transforms `color/oklch-css`, `size/px-to-rem`, and a `css/tailwind-theme` format.
* Output CSS variable naming: `--pos-color-bg-surface`, prefix `pos` to avoid clashes with embedded OSS products.
* `tokens.ts` exports `tokens.color.bg.surface` as `var(--pos-color-bg-surface)` string and `rawTokens` with resolved values for tests and Storybook docs.
* Contrast script `tokens:check` asserts `fg.default` on `bg.surface` at 4.5:1 and `fg.muted` at 3:1 for all three themes; fails the build otherwise.
* Documentation page `packages/ui/src/stories/Tokens.mdx` rendering swatches, type specimens and spacing rulers from `rawTokens`.
* `apps/web/src/main.css` imports `@paperos/ui/styles/tokens.css` then `@import "tailwindcss"` with `@theme` from `theme.css`.
DOD:
* `pnpm tokens:build` is idempotent; generated files committed and a CI step fails if they drift.
* `tokens:check` passes for light, dark and high-contrast.
* Vitest: alias resolution, transform outputs, snapshot of `tokens.css`.
* Tokens story renders in Storybook once `design-system/storybook` lands; until then a `/tokens` route in `apps/web`, screenshotted at 375, 1024 and 1920 for all three themes.

* ADR `docs/adr/0003-design-tokens.md`; CHANGELOG entry; Linear comment with Pages preview of the token page.
EDGE:
* Browsers without OKLCH (Chromium under 111): emit `@supports not (color: oklch(0% 0 0))` sRGB fallbacks generated at build time.
* Alias cycles (`a -> b -> a`) must fail the build with the path named.
* `prefers-color-scheme` vs explicit `data-theme`: attribute wins; no theme attribute follows the system.
* Fractional rem output (e.g. 0.8125rem) rounded to 4 decimals for stable snapshots.
* Tailwind class names colliding with default palette (`bg-red-500`): disable Tailwind default colours via `--color-*: initial`.

DEPS: `app-shell/monorepo-scaffold` provides `packages/ui` (soft: create the folder if absent). Consumed by `design-system/primitives`, `design-system/theming`, `design-system/motion`, `app-shell/pwa` (theme colour), `design-system/figma-sync`.
